This command is a compatibility alias of the unified `/mindie-agent` entry. Call `mindie_entry` once with `op=init` and a fresh `request_nonce` (deterministic `remote` and `components` tools remain available without `/mindie-agent`).

Supplied `contribute owner/repo ACCOUNT` arguments configure unified community knowledge sharing and sanitized fault reporting in `mindie-consent.json`; `/mindie-agent disabled` disables outbound sharing. Reuse saved choices (`contribute`, `disabled`, `read-only`, `later`) and ask only for missing fields when requested. Report local config state, background worker health, and external GitHub Issue/PR creation separately.

For GitHub sign-in or first-use workspace setup, see [GitHub Sign-In](../skills/mindie-agent/references/github-authentication.md), [用户须知](../skills/mindie-agent/references/user-notice.md), and [Workspace Setup](../skills/mindie-agent/references/workspace-setup.md).
