description: Optional inspection of one contribution batch, not ordinary transient recovery

Not the path for a transient local or network failure; the worker recovers that, and sharing-status shows it. Authentication, trust, rejected content, or invalid configuration can need an explicit user action. Optional: --batch <id>. Call `mindie_entry` once with `op=recover` and a fresh `request_nonce`. Never pass a session id. Batch id comes from this slash command's native arguments. Does not rerun the organizer, reset capture cursors, or replay failed model attempts.
