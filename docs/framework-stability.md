# 框架稳定性与验证

中文 | [English](framework-stability.en.md) · [返回文档索引](README.md)

本文说明 `mindie-agent-kimi` 的日常使用契约、测试预检命令、Windows 原子配置读写与验收边界。完整英文细则见 [`framework-stability.en.md`](framework-stability.en.md)。

## 1. 日常使用与持久选择

- 安装后的首次使用引导用户完成一次社区贡献选择；该选择跨任务、重启、更新与普通故障持久有效，后续无需手动重复激活。
- 关闭贡献时，Stop Hook 不执行采集或整理调用，而知识检索与 `remote-dev` 远端工具保持正常可用。
- 损坏的配置文件会被明确报告为故障，绝不会误判为“首次使用”而重新弹窗覆盖。

## 2. Windows 原子配置读写与确定性测试

- 共享配置存储结合删除共享读取与 Windows 原生原子重命名语义，确保并发读取者始终读取完整文档。
- 组件测试使用提交的固定解析器夹具与精确锁定的依赖版本，不探测或修改用户本机的生产环境安装。
