# 故障诊断与本地进程取消

<b>中文</b> | <a href="failure-diagnostics.en.md">English</a> · <a href="README.md">返回文档索引</a>

遵循 [MindIE Agent 工程设计原则](https://github.com/mindie-agent/mindie-agent/blob/main/docs/design-principles.md)中“工具可观察、可定位，禁止隐藏错误”的要求，`mindie-agent-kimi` 提供纯只读的状态诊断、精准的本地子进程取消清理，以及远端昇腾后台作业引用保留机制。

---

## 1. 纯只读状态诊断（`/mindie-agent:status`）

- **诊断输出内容**：报告客观的控制面事实状态（`status_facts`：`configured`、`knowledge_enabled`、`this_session` 手动激活租约状态、`diagnostics` 中的知识库配置与服务/存储/准入健康状况及关联的最近 5 次采集、索引和贡献批次，以及 `reporting` 状态），不包含任何首次引导提示字段（`first_use`、`next`、`recovery`），且无需事先通过 `/mindie-agent` 激活知识会话（无任务身份时不返回其他任务的记录）。
- **严格无副作用**：执行 `status` 绝不会初始化数据库、启动模型或后台服务、隐式绑定任务、清零失败计数或重放已消费的输入。
- **敏感信息过滤与损坏配置检测**：故障诊断投影会自动剔除模型服务商原始标准错误输出（stderr）、会话正文与 Token 凭证。若已有适配器配置文件损坏，将直接报告配置诊断错误，绝不会误判为“首次使用”重新引导。
- **远端开发独立可用**：当本地知识服务不可用时，原生 Shell/SSH 以及独立的 `remote-dev` 远端工具集仍可正常使用。

---

## 2. 本地请求取消与远端昇腾作业分离

- **前端保持实时响应**：在有界工具请求运行期间，MCP stdio 前端持续响应 `ping`、取消指令（Cancel）与标准输入关闭（`EOF`）。
- **精准回收本地子进程**：取消前台工具调用或遇到 `EOF` 时，仅终止并回收当前请求所拥有的本地辅助子进程树。
- **保留远端作业引用**：取消本地观察请求**并不代表**远端昇腾服务器上的编译或测试作业已经终止。响应结果会完整保留远端作业 ID 与投递状态；在提交新任务前，请先显式查询或停止该远端作业。远端轮询单次等待上限为 30 秒，不会改变远端作业本身的超时设置。
