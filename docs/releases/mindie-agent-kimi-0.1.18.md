# mindie-agent-kimi 0.1.18

[English](mindie-agent-kimi-0.1.18.en.md)

本维护版修复 Windows 上配置读取与设置迁移并发时的实际失败。

- 设置迁移直接复用已锁定共享运行时的原子替换机制，允许短暂读取配置的进程在现有 5 秒预算内关闭句柄。真正的权限故障和持续占用仍明确失败，不重置用户选择。
- 用户禁用贡献与设置路径迁移继续使用同一个社区设置写锁，迁移不会覆盖已保存的禁用状态。
- 发布入口显式传递主分支专用环境密钥，统一发布器在长测试前验证可用性；所有资产在草稿 ID 对应的私有对象中完成验证后，才创建精确源码 tag 并公开不可变 Release。
- 默认继续追踪最新正式组件，并保留已安装组件版本下限。独立发布不修改历史产品组合或其他仓库版本。

回归覆盖真实 Windows 读句柄导致的原子替换冲突及用户禁用与迁移并发。最终平台 CI、发布基准和旧客户端升级结果以随包报告为准；不新增 NPU 或模型性能测量声明。
