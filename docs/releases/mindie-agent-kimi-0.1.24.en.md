# mindie-agent-kimi 0.1.24

[中文](mindie-agent-kimi-0.1.24.md)

- **Headless Windows PowerShell 5.1 Scheduled-Task Readback & BOM-Free UTF-8 Fix (`updater_schedule.py`)**: Fixed `_verify_scheduled_task` under `CREATE_NO_WINDOW` where `[Console]::OutputEncoding = [Text.UTF8Encoding]::new()` both failed without a console handle (`IOException`, falling back to OEM `CP936` on non-ASCII paths) and emitted a UTF-8 BOM (`ET.ParseError`), by writing BOM-free UTF-8 bytes directly to `[Console]::OpenStandardOutput()` and stripping any leading `\ufeff`.
- **Windows Synchronous Child-Exit Semantics & User-Scoped Git Discovery (`with_runtime.py`, `mindie_launch.py`, `paths.py`)**: Replaced Windows `os.execv` / `os.execve` re-entry with synchronous `subprocess.run(..., creationflags=CREATE_NO_WINDOW)` to prevent Windows CRT parent-exit races, normalized `\\?\` prefixes and drive-letter casing in `same_interpreter`, and added `%LOCALAPPDATA%\Programs\Git` and Scoop user-scoped Git locations to `GIT_WINDOWS_LOCATIONS`.
- **WSL2 `/mnt/<drive>` Binary Isolation & DrvFS Mode Compatibility (`paths.py`, `organizer.py`, `setup.py`, `updater_schedule.py`, `updater_staging.py`, `install_kimi_plugin.py`, `community_config.py`, `component_tools.py`)**: Added `in_wsl`, `is_windows_host_binary`, `which_host_binary`, and `is_windows_or_wsl_drvfs` so WSL2 `/mnt/c/...` Windows `.exe` and extensionless shims never shadow Linux host CLIs and `doctor_isolated` tolerates `0o777` mode bits on WSL DrvFS mounts while preserving strict `0o600` checks on Linux ext4.
- **Release Selection Transport Mapping & Local HTTP Bug Isolation (`bounded.py`, `release_metadata.py`)**: Mapped transient TLS, HTTP stream-drop, and DNS failures across the `release_metadata.py select` child boundary into typed `CatalogError` (`temporary_network` / `certificate`) while keeping local `http.client` state-machine bugs (`ImproperConnectionState`, `NotConnected`, `InvalidURL`) unmasked.
