# 自动更新机制

中文 | [English](update.en.md) · [返回文档索引](README.md)

本文说明 `mindie-agent-kimi` 的后台代数（Generation）构建、原子指针切换、回滚回执与宿主重载边界。完整英文契约细则见 [`update.en.md`](update.en.md)。

## 1. 不可变代数构建与原子切换

- 更新流程在独立的代数目录中安装新版本解释器、依赖与宿主包装文件，不在正在运行的环境上原地修改。
- 仅在候选代数完成完整性校验、依赖核对与服务交接检查后，才原子更新 `current` 指针并记录更新状态回执。
- 更新过程完全无模型调用，且保留用户已保存的社区贡献选择、项目范围与独立故障上报开关。

## 2. 回滚、状态查询与卸载清理

- 若切换或服务交接中断，更新器保留明确的失败阶段与回滚回执（`rollback`），支持恢复至上一已知完好的代数。
- 卸载插件前，可通过保留启动器运行 `updater uninstall-schedule` 移除定时检查任务；若移除失败，保留配置文件并显式报错，绝不静默吞错。
